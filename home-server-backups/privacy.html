Privacy policy

This policy covers the Home Server Backups application. Last updated 19 September 2026.

Who operates it

Enrico Ghirardi, reachable at hostmaster@choco.me. The application is a personal tool used only by its operator. It is not offered to the public and has no other users.

What data it accesses

The application uses the Google Drive API to store encrypted backup files in a dedicated folder of the operator's own Google Drive. It reads, writes and deletes files in that folder. It does not access other Drive content, Gmail, Contacts, Calendar or any other Google service.

What it stores

The uploaded files are backups of the operator's home server, encrypted on that server before upload with a key that Google never receives. The application keeps a Google OAuth token on the home server so it can run unattended. No data is sent anywhere other than Google Drive and the operator's own server.

Sharing and third parties

No data is shared with, sold to or transferred to anyone. There is no analytics, advertising or tracking.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Backup files are kept according to a retention schedule and old ones are deleted automatically. The operator can revoke the application's access at any time in the Google account permissions page and delete the folder from Drive.
