Home Server Backups

What it is

Home Server Backups is a personal, single-user application run by Enrico Ghirardi. It uploads encrypted backups of a home server to a Google Drive account owned by the same person, using the open-source tools restic and rclone.

Who can use it

Nobody else. The application is not distributed, has no sign-up, and is only ever authorized against the owner's own Google account.

What it does with Google Drive

It creates a folder in the owner's Drive and reads, writes and deletes the encrypted backup files inside it. It does not read other files, contacts, mail or any other Google data.
